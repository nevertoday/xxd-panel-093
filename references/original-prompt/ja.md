# XXD Panel 093 · 日本語読解訳

アップロードされた各写真を、それぞれ独立した上質なデザインポスターにしてください。複数写真を組み合わせず、一枚の写真につき一枚を出力します。全体は3:4の縦位置とし、上下二領域の高さを厳密に1:1、各50%にします。

上半分には元写真を残し、主体の同一性、構造、姿勢、実在感、自然な光と影、元の色彩の雰囲気を維持します。芸術誌、独立出版物、展覧会写真の質感が出る程度の、ごく控えめで上質な調色だけを行います。画面に合わせて周辺環境を自然に拡張しても構いませんが、主体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真で最も識別しやすい**主体、輪郭、構造、姿勢、物語関係**を抽出し、**Geometric stylization / Geometric simplification**を特徴とするモダニズムの幾何平塗りイラストへ再構成します。幾何学的な線で主体を描写するのではなく、主体そのものを長方形、台形、三角形、円、少数の自由形へ直接圧縮します。最小限の形で最重要の識別特徴を保ち、元の対象がひと目で分かるようにします。

明確な**flattened pictorial space**を採用します。写実的な遠近、量感、光と影を弱め、前後の重なり、尺度変化、色面の積層、高低関係によって空間を作ります。複雑な建築、人物、車両、植物、器物、環境の細部は少数の大きな形の体系へ統合し、反復要素は一つの色面へまとめ、一つずつ描きません。元写真が都市風景でない場合は都市化を強制せず、人物、動物、静物、自然景観なども同じ幾何化手法で再構成します。

構図では**大きな面の比率、視覚重心、重なり、正負形、色彩リズム、余白の秩序**を重視します。主体は偏心、裁ち落とし、相互の重なり、水平・垂直方向への自然な展開が可能です。切り紙やコラージュのような平面性を持たせながら、明確な物語の中心を保ちます。すべてを均等に並べたり、画面を豊かに見せるためだけの無意味な装飾を加えたりしません。

造形は**大面積の平塗り色面＋わずかに不規則な手描きの縁＋マットなガッシュ／アクリル質感**で構成します。絵具表面は繊細で柔らかく、密度にわずかな変化と手作業の塗り重ね感を持たせます。縁にはごく軽いずれ、刷毛跡、切り紙らしさを許しますが、全体は清潔で明瞭に保ちます。デジタルグラデーション、写実的な素材再現、複雑な影、写真フィルター、滑らかすぎるベクター精度は避けます。

配色は写真の**最も明るく、鮮やかで、記憶に残る色**を抽出して再編し、現実の色をそのまま再現しません。元の色相を適度に明るく、純度高く、灰味を抑えて、限定的でありながら対比の明確な色面体系を作ります。澄んだ青、アクア、若草色、暖かな黄、コーラルオレンジ、桃色、柔らかな紫、クリーム白などへ自然に展開でき、寒暖の並置、面積差、明度階層で鮮活かつ癒やしのあるリズムを作ります。現実より自由な色でも元写真の精神と色の記憶は保ち、濁り、暗さ、モランディ調、蛍光色、安価なキャンディ色を避けます。

文字は少量だけ介入させ、固定の内容や言語をあらかじめ設定しません。写真の場所、主体、動作、感情、文化的文脈から、ごく少数の題名、語句、短い注記を自由に抽出します。**簡潔で、わずかに人文的な趣とミッドセンチュリー・モダニズム印刷の性格を持つ編集書体**を用います。文字は余白、建築や主体の軸、色面の縁、形との整列に配置し、後付けのタイトル帯ではなく幾何構成の一部にします。

全体は**Geometric urban illustration / Naïve modernist illustration / Mid-century inspired editorial illustration**の視覚性を持ち、幾何化された形、平面空間、鮮明な色面、手描きの不規則な縁、マットなガッシュ肌、専門的な編集構図を共存させます。現代的、明快、抑制的、素朴で上質に仕上げます。写実イラスト、複雑な遠近、重い光と影、カートゥーンステッカー感、滑らかなベクター感、3Dレンダリング、テンプレート的な旅行ポスターは避けます。
